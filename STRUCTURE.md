# STRUCTURE: Interview Simulator

The web app (HTML, CSS, JS) is built with Vite into `dist/`. Capacitor copies it into the Android app. The Android Gradle project lives in the **repo root** (not in an `android/` folder), set by `android.path: '.'` in `capacitor.config.ts`.

Legend: **EDIT** = safe to edit. **CAREFUL** = edit only if you know why. **DON'T TOUCH** = generated or tool-owned.

## npm scripts

| Command | What it does |
|---|---|
| `npm run dev` | Run the web app in a browser for quick UI checks (voice is hidden in the browser) |
| `npm run build` | Build the web app into `dist/` (release: no debug tools) |
| `npm run build:debug` | Build the web app with the hidden ads status panel (used for the debug APK) |
| `npm run test:ads` | Unit tests for the ad rules with mocked AdMob |
| `npm run test:voice` | Unit tests for read-along, voice filters (noise, confidence, n-best, dedupe) and the session manager (mocked plugin) |
| `npm run test:home` | Unit tests for the question of the day (same all day, new each day) |
| `npx cap sync android` | Copy `dist/` into the Android app and update plugin lists |
| `npm run android:prep` | build + cap sync together |
| `npm run icon` | Make every app icon, the splash, the Play icon and web icons from `assets/logo/glyph.svg`, then check the sizes |
| `npm run icon:check` | Check the Play icon (512x512, 32-bit, < 1 MB) and all launcher sizes |
| `npm run test:vocab` | Name matching, interview vocabulary (protected words, < 10 KB), false-positive sweep |
| `npm run test:practice` | Practice alignment (exact, substitution, missing, extra, names, score), template answer, setup rules |
| `npm run policy:page` | Make `privacy-policy-site/index.html` from `PRIVACY_POLICY.md` |
| `npm run store:assets` | Make the 512 icon and feature graphic |
